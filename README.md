# LeadHarvest

LeadHarvest is a Google Maps lead generation tool built with Python and Playwright.

This repository currently contains the first working version of the project i.e. a command-line scraper capable of searching Google Maps, collecting business information, and exporting the results to Excel.

The goal of this version was just to prove that the core idea works.

## Project Status

Version 1 (Prototype)

This version intentionally prioritizes functionality over architecture. The objective was to understand the problem, build a working solution, and establish a foundation for future iterations.
